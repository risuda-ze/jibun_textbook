## 実APIでの確認は未実施

APIキーは本人だけが扱う決まりなので、実際の Anthropic API を呼ぶ確認はしていない。
AI層は偽クライアントで、リクエストの形と分岐（`pause_turn` の続行、検索エラー、`parsed_output` が null、`refusal`、
`max_tokens`、ネットワーク断、認証失敗、利用上限）を確かめた。**実際の応答で構造化出力のスキーマが通るか、
Web検索ツールの型 `web_search_20260209` が選んだモデルで受け付けられるかは、キーを入れて1回生成するまで分からない。**

確かめる手順:

1. 「つくる」→「使うAI」で Anthropic API を選び、キーを入れる
2. 学びたいことを書いて設計を作る。右の「AIの作業」の下に検索回数とトークンが出る
3. ロードマップで節を選び「この節の資料を生成」。完了時の通知に検索回数とトークンが出る
4. エラーが出たら文面をそのまま `docs/notes.md` の「実APIで分かったこと」に書く
