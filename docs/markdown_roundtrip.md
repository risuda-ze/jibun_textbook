# Markdown 往復（見たまま編集）の仕様

本文は Markdown で保存し、画面では HTML にして見たまま編集する。編集を確定するとき HTML を Markdown に戻す。
この往復で **どの記法が保たれ、どれが変わり、どれが崩れるか** を実測で固定した文書。
結果表の各行は `tests/md_roundtrip.test.ts` の期待値と対応している。**表を変えるときはテストも変える**（逆も同じ）。

## 往復の仕組み

| 向き | 関数 | 中身 |
|---|---|---|
| 表示（md → HTML） | `mdToHtml()`（`src/lib/md.ts`） | `marked`（`gfm: true`, `breaks: true`）→ `DOMPurify.sanitize()`。表示は `dangerouslySetInnerHTML`、編集は `contenteditable` に流し込む |
| 確定（HTML → md） | `htmlToMd()` | `DOMPurify.sanitize()` → `turndown`（`headingStyle: atx`, `codeBlockStyle: fenced`, `bulletListMarker: -`, `emDelimiter: *`）＋ `turndown-plugin-gfm`（表・取り消し線・チェックリスト）。`contenteditable` が作る `<div>` は段落として扱う。3連続以上の改行は2つに詰める |

- 確定は `Editable`（`src/ui/blocks.tsx`）の blur 時。**フォーカス前後の HTML が同じなら何もしない**。触っていないブロックが正規化だけで「自分で修正」になるのを防ぐため
- `breaks: true` は「Markdown の単一改行を `<br>` にする」設定。AI の出力やノートの改行がそのまま改行として見える。確定時は表の外の `<br>` を改行1つに戻す（turndown 既定の行末空白2つは付けない。#148）
- 見たまま編集の **Enter は行（`<br>`）、空行は段落**（入力欄と同じ規則。#148）。contenteditable の既定の Enter は段落（`<p>`/`<div>`）を作るため、1行ずつ打った表や箇条書きが Markdown として成立しなかった。`Editable` の `onKeyDown` が Enter を `<br>` の差し込みに置き換え、直前が `<br>`（空行・行頭）の Enter だけブラウザ既定に任せてブロックを分ける（`<li>` なら次の項目）。Shift+Enter は既定（`<br>`）、IME 変換中の Enter（`isComposing`）は触らない。コードブロックの中も既定のまま。ブロック末尾に残った `<br>` は確定時に消す（li に残ると tight list が loose になるため）

## 記法ごとの結果

判定の意味:

- **保たれる**: 往復後の Markdown が入力と一字一句同じ
- **変わるが意味は同じ**: 文字列は変わるが、もう一度描画すると同じ HTML になり、2回目の往復では変わらない
- **崩れる / 落ちる**: 意味が変わる、または往復のたびに変わり続ける

| 記法 | 入力 | 往復後 | 判定 | 備考 |
|---|---|---|---|---|
| 見出し | `# 見出し1` … `### 見出し3` | 同じ | 保たれる | |
| 強調・斜体 | `**強調** *斜体* ***両方***` | 同じ | 保たれる | |
| 取り消し線 | `~~消した~~` | `~消した~` | 変わるが意味は同じ | gfm プラグインは `~` 1つで出す。marked はどちらも打ち消し線にする |
| 箇条書き | `- 一` | `-   一` | 変わるが意味は同じ | turndown は記号の後を空白3つにする |
| 番号付き | `1. 一` | `1.  一` | 変わるが意味は同じ | 番号の後が空白2つ |
| 入れ子のリスト | `- 親` / 2字下げ `- 子` / 4字下げ `- 孫` | 字下げが4つずつ | 変わるが意味は同じ | 描画は同じ。`docs/images/md_nested_list.png` |
| 番号付きの入れ子 | `1. 一` / 3字下げ `- 一の子` | 字下げが4つ | 変わるが意味は同じ | |
| コードブロック | ` ``` … ``` ` | 同じ | 保たれる | 中身の記号・改行はそのまま |
| 言語つきコードブロック | ` ```rust ` | 同じ | 保たれる | 言語名も残る |
| インラインコード | `` `cargo run` `` | 同じ | 保たれる | |
| 表 | `\|---\|---\|` | `\| --- \| --- \|` | 変わるが意味は同じ | 区切り行が空白つきに揃う。`docs/images/md_table.png` |
| 表の揃え | `\|:--\|:-:\|--:\|` | `\| :-- \| :-: \| --: \|` | 変わるが意味は同じ | 揃えは残る |
| 表の中の改行 | `一行目<br>二行目` | 同じ | 保たれる | セルの中の `<br>` は `<br>` のまま出す（#48）。表の外の `<br>` は改行1つになる（#148） |
| 引用 | `> 一行目` / `> 二行目` | 同じ | 保たれる | #148 までは行末に空白2つが付いていた |
| リンク | `[Rust Book](https://…)` | 同じ | 保たれる | |
| 画像 | `![説明](https://…/a.png)` | 同じ | 保たれる | |
| 画像（data URL） | `![](data:image/png;base64,…)` | 同じ | 保たれる | ノートの画像は別の欄（`images`）に持つので本文には通常入らない |
| 水平線 | `---` | `* * *` | 変わるが意味は同じ | |
| 単一改行 | `一行目` ＋改行＋`二行目` | 同じ | 保たれる | `breaks: true` で `<br>` になり、確定時に改行1つに戻る（#148 までは行末に空白2つが付いていた） |
| 段落 | 空行で区切る | 同じ | 保たれる | |
| 見たまま編集の Enter | Enter で1行ずつ `\|a\|b\|` `\|-\|-\|` `\|1\|2\|` を打つ / Enter 2回で次の段落 | `\|a\|b\|` ＋改行＋`\|-\|-\|` … / 空行で区切られた段落 | 保たれる | **Enter は行、空行は段落（入力欄と同じ）**（#148）。1行ずつ打った表・箇条書き・番号付きが入力欄と同じに描画される。Shift+Enter も行。IME 変換中の Enter は改行にならない |
| チェックリスト | `- [ ] 未` / `- [x] 済` | `-   [ ] 未` | 変わるが意味は同じ | チェックの状態は残る。画面上の箱はクリックで切り替えられ、Markdown 側の `[ ]` / `[x]` が書き換わる（#56） |
| HTML の直書き | `<b>太字</b><span style="color:red">赤</span>` | `**太字**と赤` | 落ちる（意図どおり） | DOMPurify が許す要素だけ残り、`style` などの装飾は落ちる。色付き文字は書けない |
| 危険な HTML | `<img onerror>` `<script>` | 除去 | 落ちる（意図どおり） | 表示時と確定時の両方で DOMPurify を通す |
| エスケープ | `1 < 2 && 3 > 2 "引用符"` | 同じ | 保たれる | |
| 記号としての `*` | `5*3` | `5\*3` | 変わるが意味は同じ | 強調と区別するため `\` が付く |
| 長い文 | 120字の1行 | 同じ | 保たれる | 折り返しは表示だけ。改行は入らない |
| 見たまま編集中に文字で打った記法 | `**文**` `` `文` `` `[文](URL)` `# 見出し` `- 項目` を contenteditable に入力 | 打った文字のまま | 保たれる | turndown のエスケープを無効にしている（`td.escape`、#147）ので、編集中に打った文字は入力欄と同じく Markdown として解釈される。文字として残したい記号は `\*` のように自分でエスケープする。**注意**: 元の本文で `\*` と文字扱いだった記号は、その段落を編集で確定すると Markdown として解釈される（#76 #145 の記法ごとの置換は不要になり削除） |

## 既知の制約と扱い

| 事項 | 扱い |
|---|---|
| 表の中の改行 | 対応済み（#48）。turndown の規則でセル内の `<br>` を `<br>` のまま出す |
| 色付き文字・`style` | **書かない約束**。DOMPurify の方針（安全側）を優先する。強調は `**` か引用で表す |
| 行末の空白2つ | 付けない（#148）。表の外の `<br>` は改行1つに戻す。`breaks: true` なので描画は同じ |
| リストの空白と字下げ | **許容**。turndown の既定に揃える。読みやすさは変わらない |
| 見出しの記法 | `#` 形式（atx）に統一される。`===` の下線形式は `#` になる |

## 確かめ方

```bash
npm test -- tests/md_roundtrip.test.ts
```
