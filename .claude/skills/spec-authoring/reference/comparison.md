# 案の比較提示フォーマット

対話型の草案を「対話案」、自律型の各案を「案A / 案B …」として同じ表に並べる。

## 比較表

| 観点 | 対話案 | 案A | 案B |
| --- | --- | --- | --- |
| 目的 | | | |
| 対象範囲（含む / 含まない） | | | |
| 受入条件の数と主な内容 | | | |
| 影響範囲（レイヤー・ファイル数） | | | |
| 正本仕様との関係（変更あり / なし） | | | |
| 制約・注意 | | | |
| 根拠 / 仮定 | ユーザー回答 | 仮定 | 仮定 |

## 差分の要約

案の間で結論が異なる論点だけを箇条書きにする（同じ点は書かない）。

## ユーザーへの問い

- どの案を基にするか（組み合わせも可）
- 組み合わせる場合、どの論点をどの案から採るか

推奨は自律型が付けたものをそのまま転記し、提示側は追加しない。
