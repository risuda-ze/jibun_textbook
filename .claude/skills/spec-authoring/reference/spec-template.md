# 変更仕様テンプレート

## 変更名
一意な名前（kebab-case のファイル名にもなる）。

## 目的
何のために変えるか。誰（配信者 / チームメンバー / 運営）のどの困りごとを解消するか、1〜2文。

## 対象範囲
- 含む: 機能・画面・API
- 含まない: 今回触らないことを明示

## 正本仕様との関係
- 参照: `docs/仕様・計画/<カテゴリ>/<ファイル>` の該当節
- 仕様変更の有無: なし / あり（変更内容と、実装後に更新する正本ファイル）

## 受入条件
| ID | 入力・操作 | 期待結果 |
| --- | --- | --- |
| AC-1 | | |

## 影響ファイル（想定）
- `src/...` / `functions/src/...` / `tests/unit/...`

## 制約・注意
権限（ロール）・プラン制限・JST・外部サービス（Discord / Stripe / メール）失敗時の扱いなど、該当するもの。

## 根拠・仮定
- 対話型: 各項目の根拠となったユーザー回答（ラウンド番号）
- 自律型: 置いた仮定と、ユーザー確認が必要な点

## 用語追加候補
無ければ「なし」。
