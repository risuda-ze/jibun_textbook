# 報告フォーマット

## 回帰確認結果

| コマンド | 結果 | 備考 |
| --- | --- | --- |
| pnpm typecheck | OK / NG | NG の場合はエラー件数 |
| pnpm lint | OK / NG | NG の場合はエラー件数 |
| pnpm test | OK / NG | 実行数 / 成功 / 失敗 |
| functions typecheck | OK / NG / 対象外 | |
| pnpm test:e2e:smoke | OK / NG / 対象外 / 実行不可 | UI 変更時のみ。実行不可なら理由 |

失敗がある場合は下記に該当出力を貼る（ファイル:行 を含める）。

```
（失敗出力）
```

## 実装結果（実装エージェントが返す形式）

- **対象**: 変更単位名または指示内容
- **変更ファイル**: パスと変更概要を1行ずつ
- **追加・更新テスト**: パスとケース名
- **回帰確認結果**: 上の表
- **委譲したタスク**（complex-implementer のみ）: タスク名 / 担当 / 結果
- **指摘への対応**（修正モードのみ）: 指摘ID / 対応（修正・不修正）/ 理由
- **未確定事項**: 呼び出し元の判断が必要な点。無ければ「なし」
- **範囲外の要修正点**: 気づいたが着手していない点。無ければ「なし」
